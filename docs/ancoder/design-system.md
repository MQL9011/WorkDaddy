# WorkDaddy 设计规范（DSH Desktop 风格）

本文件定义 WorkDaddy 的视觉语言。取值来自 [DeepSeek Harness Desktop](https://github.com/anywhere-labs/deepseek-harness-desktop)
官方界面预览图 `assets/desktop-preview.png` 的**逐像素采样**，不是目测估计。

上游 gooey-pi 已经是 CSS 变量驱动的主题系统（`src/styles/base.css` 里 `:root` 与
`:root[data-theme="dark"]` 两套 token），所以换肤 = 换 token 值 + 改少数组件规则，
不需要重写样式架构。

---

## 1. 色板

### 1.1 深色主题（主推，DSH 默认形态）

| Token | 值 | 用途 | 采样来源 |
| --- | --- | --- | --- |
| `--canvas` | `#151517` | 会话主区背景 | 会话区大面积 |
| `--sidebar` | `#272728` | 左侧栏背景、品牌区 | 侧栏大面积 |
| `--surface-raised` | `#2C2C2E` | 用户消息气泡、输入框容器 | 气泡与 composer |
| `--surface-selected` | `#383838` | 会话列表选中项 | 选中会话行 |
| `--surface-control` | `#44454A` | 「新会话」等主要按钮底色 | 新会话按钮 |
| `--text` | `#F9FAFB` | 主文字 | 正文 |
| `--text-secondary` | `#A1A1A6` | 次级文字、元信息行 | 推导 |
| `--text-tertiary` | `#7E7F82` | 时间戳、状态栏 | 按钮内次级文字 |
| `--border` | `#2F2F31` | 分隔线（侧栏/主区之间几乎不可见） | 推导 |
| `--accent` | `#4D6BFE` | 品牌蓝：发送按钮、主行动点 | DSH 品牌色 |
| `--accent-soft` | `#749DF7` | 激活 tab 下划线、链接 | tab 下划线 |
| `--accent-idle` | `#49597E` | 发送按钮未就绪态 | 发送按钮 |

### 1.2 浅色主题

保留上游浅色 token 结构，仅把强调色从 `--prime: #5f4bd3` 换成 `--accent: #4D6BFE`，
其余中性色沿用上游（上游浅色调校过对比度，没有理由推翻）。

### 1.3 语义色

`--success` / `--warning` / `--danger` / `--diff-*` 全部沿用上游取值。
diff 的绿红是代码审阅的既有共识，不参与品牌换肤。

```
│              ├────────────────────────────────────────────────┤
│ 工作区 🔍⚙＋  │                                                │
│  📁 project   │              会 话 流                          │
│   会话  2小时 │                                                │
│   会话  昨天  │                                                │
│              ├────────────────────────────────────────────────┤
│              │ ╭────────────────────────────────────────────╮ │
│              │ │ 给智能体发消息                              │ │
│              │ │ ＋  权限 ⌄            模型 ⌄  ○     ( ↑ )  │ │
│              │ ╰────────────────────────────────────────────╯ │

```

关键尺寸：

| 元素 | 规格 |
| --- | --- |
| 侧栏宽度 | 280px，可折叠（品牌区右侧折叠图标） |
| 侧栏/主区分隔 | 靠背景色差区分，`--border` 仅 1px 且极低对比 |
| 输入框圆角 | 20px（大圆角是 DSH 观感的核心特征之一） |
| 用户气泡 | 右对齐、`--surface-raised`、圆角 18px、最大宽度 70% |
| 助手消息 | **无气泡**，全宽正文，仅靠留白区分 |
| 发送按钮 | 40px 圆形，`--accent` 实心，白色箭头 |
| 主按钮圆角 | 10px |
| 会话行圆角 | 8px |
| 基础字号 | 13px（沿用上游），正文行高 1.7 |

## 3. 组件规则

### 3.1 会话流

- **用户消息**：右对齐灰底气泡，无头像、无昵称。
- **助手消息**：全宽纯文本，Markdown 渲染，无气泡无边框。
- **元信息行**：小图标 + 灰色小字单行，例如「上下文注入 · @xxx」「Think · 推理摘要首句…」，
  默认折叠成一行，点击展开。
- **消息操作**：助手消息底部一行图标（复制 / 赞 / 踩 / 重试），常驻但低对比，hover 提亮。
- **工具调用卡片**：沿用上游 `src/components/transcript/` 的实现，仅换配色与圆角。

### 3.2 输入区

一个大圆角容器内分两行：

- 上：多行输入，placeholder「给智能体发消息」。
- 下：左 `＋`（附件）、权限 chip（映射 omp 的 `--approval-mode`）；
  右为模型选择器、思考等级、发送按钮。

### 3.3 状态条

输入框下方单行，`--text-tertiary`，以 ` | ` 分段。字段映射 omp RPC 的 `usage` / `session_stats`：
轮次·步数、LLM 耗时、首 token 延迟与 tok/s、缓存命中率、输入/输出 token。

### 3.4 顶部 tab

「对话 / 轨迹」两个 tab，激活项 2px `--accent-soft` 下划线 + 主文字色，未激活为 `--text-secondary`。
**轨迹 tab 是我们放技能调用时间线的位置**，不是简单照抄。

## 4. 与 DSH 的刻意差异

我们参考它的观感，不复制它的信息架构。三处必须不同：

1. **侧栏底部增加「技能」入口**，与「设置」并列。技能是本产品的一等公民，不能藏进设置页。
2. **轨迹 tab 承载技能命中时间线**：哪一步读了哪个 `skill://`、由哪个 provider 提供。
   DSH 的轨迹只有工具调用。
3. **权限 chip 语义不同**：DSH 是 Workspace Write，我们映射 omp 的
   `always-ask / write / yolo` 三档，文案面向不懂终端的用户重写。
